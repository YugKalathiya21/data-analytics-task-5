# 📊 Statistical Analysis of Data

## Project Overview

This project demonstrates basic statistical analysis using Python, NumPy, and SciPy. Various statistical measures such as Mean, Median, Mode, and T-Test were implemented to analyze experimental data.

---

## Objectives

- Calculate Mean, Median, and Mode
- Perform Statistical Hypothesis Testing
- Compute P-value
- Interpret statistical results

---

## Tools Used

- Python
- NumPy
- SciPy
- Google Colab

---

## Statistical Methods

### Mean
Average value of the dataset.

### Median
Middle value of the sorted dataset.

### Mode
Most frequently occurring value.

### T-Test
Used to compare sample mean with a reference value.

### P-Value
Used to determine statistical significance.
